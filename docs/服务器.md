### 登录

**SSH（推荐，免密码）**

```
ssh -i ~/.ssh/tomb_relay administrator@47.111.139.53
```

- 用户名：`administrator`
- 私钥：本机 `C:\Users\Martis\.ssh\tomb_relay`（ed25519，公钥 `tomb_relay.pub` 已写进服务器的 `C:\ProgramData\ssh\administrators_authorized_keys`）
- 远程默认是 cmd，中文输出是 GBK 编码，在 Git Bash 里看乱码时在命令后面加 `| iconv -f gbk -t utf-8`
- 换电脑登录：把 `tomb_relay` 私钥拷到新电脑的 `~/.ssh/`，或者在服务器上把新电脑的公钥追加到上面那个文件

**RDP / 云助手（备用）**

阿里云控制台 → 实例 → 远程连接。登录密码在控制台“重置实例密码”里设置，**不记录在这里**。

### 服务器上的东西

| 路径 | 内容 |

端口：**UDP 7777** 给加入的队友连，**UDP 7778** 收房主的心跳。服务器只转发数据包、不跑物理，CPU 和内存几乎不占。

### 常用操作

```
# 看日志最后几行
ssh -i ~/.ssh/tomb_relay administrator@47.111.139.53 "powershell -c Get-Content C:\tomb\relay.log -Tail 20"

# 看中转程序在不在跑（应该能看到 0.0.0.0:7777 和 0.0.0.0:7778）
ssh -i ~/.ssh/tomb_relay administrator@47.111.139.53 "netstat -ano -p udp | findstr 777"

# 更新中转程序：传新文件，然后结束进程，bat 会在 3 秒内自动重开
scp -i ~/.ssh/tomb_relay tools/relay.py administrator@47.111.139.53:C:/tomb/
ssh -i ~/.ssh/tomb_relay administrator@47.111.139.53 "taskkill /f /im python.exe"

# 手动重启计划任务
ssh -i ~/.ssh/tomb_relay administrator@47.111.139.53 "schtasks /end /tn tomb-relay & schtasks /run /tn tomb-relay"
```

### 实测

- 2026-10-24 从开发机测：UDP 往返延迟中位数 44 ms，50 个包 0 丢失
- 同一天用房间号走服务器完成一次房主 + 队友联机测试，画面同步正常

### 注意

- 在 Git Bash 里写 Windows 路径的 bat 文件时，不要用 `printf` / `echo -e`：`C:\tomb` 里的 `\t` 会变成制表符
- 远程执行 `pkill -f 名字` 之类的命令时，名字会出现在 ssh 自己的命令行里，可能把 ssh 会话一起杀掉；改用脚本文件执行
