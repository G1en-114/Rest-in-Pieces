# 《棺不住 Rest in Pieces》试玩文档

> **一句话介绍**：一群站不稳的抬棺人，要把棺材抬过中国、埃及、墨西哥三座不讲物理的灵堂——会塌的地板、把人撞飞的机关、靠视错觉才接得上的断桥，逝者掉出来可就不体面了。

## 一、启动游戏

1. 解压「棺不住_评委试玩」压缩包，双击 **棺不住.exe**。
2. Windows 提示“Windows 已保护你的电脑”时，点 **更多信息 → 仍要运行**。（游戏没有做数字签名，所以会有这个提示。）
3. 第一次打开要编译着色器，可能会黑屏或卡十几秒，之后再打开就快了。

**运行环境**：Windows 10 / 11（64 位），支持 Vulkan 的显卡（近几年的独显、核显都可以）。不用安装任何东西，不用联网（联机模式除外）。

## 二、选一个模式

开始界面左边是一列白字，鼠标点或者按前面的数字键：

| 按键 | 模式 | 说明 |
| --- | --- | --- |
| **2** | **两个人抬（最推荐）** | 两位评委共用一个键盘，左右分屏第一人称。最能体现“配合不默契”的乐趣 |
| 1 | 一个人抬 | 你 + 电脑队友。队友会跟着你抓、跟着你走 |
| 3 / 4 | 建房间 / 加入房间 | 两台电脑联网一起玩，见第六节 |
| Q | 退出 | |

选好模式后选关、选房间。**可以直接挑任意一个房间开始**，不用从头打（从中间开始不计最好评级）。

## 三、操作

**一个人抬、联机、两个人抬的 P1（键鼠）**

| 操作 | 按键 |
| --- | --- |
| 走 | W A S D |
| 看路 / 控制手的高度 | 鼠标（往下看就会弯腰去够地上的东西） |
| 左手抓 / 右手抓 | 鼠标左键 / 右键（**按住不放**才抓着） |
| 跳 | 空格 |
| 第一人称 ⇄ 俯视 | V |
| 旋转俯视视角 | Q / E（每次 45°） |
| 缩放俯视视角 | 鼠标滚轮 |
| 举起相机 / 拍照（墨西哥关） | C / 鼠标左键 |

**两个人抬的 P2（键盘右半边）**

| 操作 | 按键 |
| --- | --- |
| 走 / 转身 | ↑ ↓ / ← →（俯视时 ← → 是平移） |
| 抬头 / 低头 | ' / ; |
| 左手抓 / 右手抓 | , / . |
| 跳 | / |
| 举起相机 / 拍照（墨西哥关） | [ / ] |
| 分屏第一人称 ⇄ 共享俯视 | V 或 Enter |

**通用**：R 回到检查点 · F5 本关重来 · Esc 释放鼠标 / 回菜单 · F1 退出联机

## 四、推荐试玩路线（约 10 分钟）

| 顺序 | 关卡 · 房间 | 看什么 |
| --- | --- | --- |
| 1 | 中国 · 第 1 间「入殓间」 | 学抬棺：两人都抓稳把手再走，一个人松手棺材就歪 |
| 2 | 中国 · 第 3 间「纸扎仓库」 | 纸扎推墙会把人撞飞，第一人称下视角跟着翻滚；有一条二楼近路 |
| 3 | 中国 · 第 6 间「断桥」 | **核心机关**：切到俯视（V），按 Q / E 把视角转到断桥“看起来接上了”，桥就真的接上了。第一人称的人看到的永远是断桥，只能踩着脚下的金色虚线、相信队友走过去 |
| 4 | 埃及 · 第 5 间「滚石长廊」 | 巨石从身后滚过来，快跑 |
| 5 | 墨西哥 · 第 1 间「万寿菊墓园」 | 拍照修路：站进地上相机标记的圈里，按 C 举起相机，取景框变金色时拍照，远处断掉的路就会变成一段实的路 |

时间充裕的话，从中国关第 1 间一路打到灵台，能看到完整的结算和奖章。

## 五、玩法要点

- **两个人都抓稳了再走**。棺材靠物理抬着，步调不一致就会歪、会撞墙。
- **体面值**：起始 100 分，只在出事时扣：棺材颠一下 -2、撞墙 -3、棺材摔地 -8、逝者掉出来 -10、掉进深渊 -20。
- **被机关撞飞不扣分**，但人一飞，棺材多半就掉了。
- 逝者或棺材掉在地上：往下看，弯腰把它捡回来。
- 每关都藏着**近路**（比如弹簧板）和**假墙后面的秘密**，地上的花圈可以加分。
- 把棺材放上灵台就算送达，结算有评级（S / A / B / C）、称号（比如「赶着投胎」「人在空中飞，棺在地上爬」）和奖章（空中飞人、稳如泰山、探险家、一镜到底……）。

## 六、联机试玩（两台电脑）

1. 两台电脑都打开同一个版本的游戏。
2. 房主按 **3 建房间**，选关、选房间。屏幕上会显示一个 **4 位房间号**。
3. 队友按 **4 加入房间**，输入房间号，按 Enter，就会自动进入房主选的关卡。

联机通过我们部署在杭州的中转服务器，两台电脑不用在同一个网络。如果现场网络连不上服务器，两台电脑在同一个局域网时，也可以在“加入房间”里直接输入房主屏幕上显示的 IP 地址。

## 七、常见问题

| 问题 | 解决 |
| --- | --- |
| 打不开，提示“已保护你的电脑” | 点“更多信息”→“仍要运行” |
| 第一次打开黑屏很久 | 正在编译着色器，等十几秒 |
| 鼠标被锁在窗口里 | 按 Esc |
| 卡住了 / 掉下去了 | R 回检查点，F5 本关重来 |
| 联机连不上 | 确认两边是同一个版本；Windows 防火墙弹窗时点“允许访问” |

存档在 `%APPDATA%\Godot\app_userdata\抬棺\`，删掉就是全新开始。
