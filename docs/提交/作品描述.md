# 《棺不住 Rest in Pieces》作品描述

## 一句话介绍

一群想体面送别、却总是人仰马翻的抬棺人，和队友一起把最后一程抬成大型翻车现场。

## 短版

《棺不住 Rest in Pieces》是一款以“抬棺舞”为灵感的搞笑物理协作游戏。玩家和队友共同抬起棺材，穿过中国、埃及、墨西哥三种葬礼文化主题的 20 个房间。步调不一，棺材就歪；机关一撞，队友就飞；颠得太狠，连逝者都会加入混乱。游戏把布娃娃物理、第一人称协作与视错觉解谜结合起来，并提供 Lux3D 照片角色工作台，让玩家使用自己的平台密钥生成并应用个性化形象。目标很庄重，过程很狼狈，队友之间的沟通和失误就是最好的笑点。

## 完整版

《棺不住 Rest in Pieces》是一款搞笑物理协作游戏。玩家扮演一群站不太稳的抬棺人，与队友抓住同一口棺材，在机关密布的灵堂中完成一次尽量体面的送别。

棺材、抬棺人的身体与双手、逝者的布娃娃部件都参与物理模拟。两个人的方向、速度和抓握高度会共同影响棺材的姿态：走快一步，棺材可能倾斜；松开一只手，队友就得独自稳住重量；撞上机关，人可能飞出去，逝者也可能被颠出棺材。玩家要在混乱中重新集合、捡回棺材，再一起向前。

游戏目前包含中国“殡仪馆的一天”、埃及“法老的最后一程”、墨西哥“万寿菊之路”三关，共 20 个房间。纸扎仓库、古墓甬道与亡灵节街市各有自己的机关节奏：会塌的地板、推墙、滚石、刀摆、花船和烟花城堡，让每一次配合都充满变数。

视角也是解谜工具。在“信任之桥”中，俯视的玩家旋转视角，使断桥在视觉上接通；第一人称的队友则要相信指引，踏过自己眼前仍然断开的道路。墨西哥关的相机谜题让玩家在特定位置拍照，把远处的道路沿着视线变成可走的照片路面。一个人看见答案，另一个人负责执行，沟通本身成为玩法。

AHOLO Lux3D 为游戏提供默认抬棺人、自动绑骨和 11 个主题道具模型。新增的照片角色工作台进一步把这条资产流程带到玩家面前：输入自己的平台 API Key，选择全身照片，生成并自动绑骨后，应用到抬棺人或逝者身上。角色外观可以改变，原有物理结构和协作规则继续工作。工作台支持生成任务恢复、已有 GLB 导入和默认外观恢复，密钥保留在本机内存中，联机只交换模型。

游戏支持单人搭配电脑队友、本地双人分屏和双人联机。掉落后可以从检查点继续，结算则把颠簸、坠落、探索与近路变成体面值、称号和奖章。我们希望玩家记住的，是“刚才你为什么突然松手”和“人都飞出去了，你还在抬”这样的共同经历。

## 展示与验收说明

照片工作台的上传、生成、绑骨、下载、异常恢复和模型接入已实现，并于 2026-10-27 用国内官方 API 真实验收：三张 T 字站姿的正面全身图（由 Lux3D 模型渲染，非真人照片）都生成、绑骨成功，其中一次网络中断后用任务恢复接上原任务，未重复扣费。双臂弯曲的输入会被平台拒绝绑骨。宽檐帽、长裙类模型当逝者时存在网格撕裂，当抬棺人正常。4 人联机和 3DGS 背景仍属于后续计划。
