# 多房间长关卡、选关与结算：设计

2026-10-20 · 已与用户确认

## 目标

- 关卡可选，每关一个国家风格。最终目标是 5 关：中式（教学关）、埃及、加纳、墨西哥、日本
- 每个正式关 40–60 分钟，由 10–12 个房间组成
- 逝者掉出来不再扣分过快；只要把棺材和逝者都放上灵台就算送达，然后给出评价

本轮范围：框架，加上中式教学关的移植，加上**埃及完整长关**。埃及关试玩确认后，再按同样模式做加纳、墨西哥、日本。

## 一、系统

### 流程

选模式（1 单人 / 2 双人 / 3 建房 / 4 加入）→ 选关（国家卡片，显示关卡名和最好评级）→ 选房间（默认「继续」存档房间，也可「从头开始」，或直接选任意房间）→ 游戏 → 送达后出结算面板（R 重来 · N 下一关 · M 回选关）。

联机时由房主选关和房间，加入方自动进入同一关同一房间（房主用可靠 RPC 发关卡 id 和房间号）。

### 代码结构

| 文件 | 职责 |
| --- | --- |
| `scripts/level_base.gd`（`class_name Level`） | 通用搭建工具（地面、墙、碰撞盒、道具摆放、灯）；关卡接口：房间列表、每个房间的检查点与电脑队伍路线、灵台位置、环境配色、`tick(t)`、联机状态打包与恢复、需要同步的刚体列表、每帧的关卡逻辑钩子 |
| `scripts/levels/china.gd` | 现在的第一关（教学关），断桥逻辑从 main.gd 挪进来 |
| `scripts/levels/egypt.gd` | 埃及关；机关部件可以拆到 `scripts/levels/egypt_*.gd` |
| `scripts/props.gd` / `props_egypt.gd` | 各国道具 |
| `scripts/score.gd` | 体面值事件、送达判定所需的统计、评级、加减分明细、称号 |
| `scripts/menu.gd` | 选模式、选关、选房间界面，以及结算面板 |
| `scripts/save.gd` | `user://save.cfg`：每关的最好评级、存档房间、存档时的体面值与用时 |
| `scripts/main.gd` | 只负责组装：玩家控制、镜头、联机、调用关卡与计分 |

### 关卡接口（Level 基类）

- `rooms: Array`：每个房间包含名字、检查点（整队出生的位置和朝向）、电脑队伍路线（坐标点，或 `"wait:<标签>"` 形式的等待指令）
- `goal`：灵台的位置与大小；`kill_y`：掉到这个高度以下算坠落
- `room_at(pos) -> int`：棺材现在在第几个房间，用于推进检查点
- `env()`：天空、雾、太阳的参数
- `tick(t)`：按时间运动的机关。房主传 `sim_time`，加入方传插值后的房主时间
- `physics_update(game)`：每个物理帧的关卡逻辑（断桥平移、塌陷地板、压力板）
- `net_bodies() -> Array[RigidBody3D]`：需要同步位置的刚体（石块、滚石），接在整队刚体后面一起进快照
- `net_state() -> PackedFloat32Array` / `apply_net_state(a)`：有状态的机关（塌陷地板、门）
- `bot_can_go(tag) -> bool`：电脑队伍在等待指令处是否可以出发
- 信号 `bonus(amount, text)`、`notice(text)`、`penalty(amount, text)`

### 检查点与存档

- 棺材进入新房间后，检查点更新为该房间的入口，同时写入存档（关卡、房间、体面值、用时）
- 坠落或按 R：整队回到当前房间的检查点，坠落扣 30
- 从中间房间开始的一局，结算时标注「非完整通关」，不更新最好评级

### 扣分规则

| 事件 | 规则 |
| --- | --- |
| 逝者掉出来 | 每次扣 10；在棺材外面持续 1 秒才算一次，塞回去也要在里面持续 1 秒才重新计数 |
| 棺材倾斜 | 只在逝者躺在棺材里时计算，超过 20° 后按每秒 3 × 倾角 / 20 扣分（原来的一半） |
| 摔棺材 / 撞墙 / 坠落 | 规则不变（-15 / -5 / -30） |
| 关卡机关（飞镖、滚石等） | 由关卡通过 `penalty` 信号报告，带冷却时间 |

### 送达与结算

- 送达条件：棺材倾角小于 25°、水平落在灵台上，逝者的躯干在灵台范围内（在棺材里或直接放在灵台上都行），持续 1.5 秒
- 明细：基础体面值（包含花圈）；逝者在棺材里 +20；全程没掉出来过 +10；用时低于该关标准用时 +10
- 评级：S ≥ 130，A ≥ 100，B ≥ 70，C ≥ 40，其余为 D
- 称号（按优先级取第一个符合的）：
  1. 体面值 < 0 →「社死现场」
  2. 逝者掉出来 ≥ 3 次 →「逝者表示很无语」
  3. 逝者不在棺材里 →「人去了，棺材还在」
  4. 拿到 S →「年度最佳抬棺人」
  5. 用时低于标准的 60% →「赶着投胎」
  6. 坠落 ≥ 3 次 →「深渊常客」
  7. 其余 →「平平安安」

## 二、埃及关「法老的最后一程」

从沙漠进入金字塔，一路往下，房间之间用短甬道连接。

| # | 房间 | 机关 |
| --- | --- | --- |
| 1 | 沙漠入口 | 斯芬克斯像；沙地让移动减速（抓地力和速度下降）；上下沙坡 |
| 2 | 飞镖甬道 | 墙孔按节奏射出飞镖，射中的人被推开并扣分 |
| 3 | 塌陷地板厅 | 石砖被踩 1 秒后塌落，8 秒后复原 |
| 4 | 封印石门 | 把大石块推上压力板，石门才升起；压力板上没东西时门落下 |
| 5 | 滚石走廊 | 巨石定时从斜坡滚下，两侧有壁龛可躲；被撞会被推开并扣分 |
| 6 | 深渊窄梁 | 窄梁宽度只够一前一后，得把棺材转成纵向抬 |
| 7 | 升降石台 | 石台交替升降，台面对齐时才能跨过去 |
| 8 | 天平桥 | 桥面绕中轴转动，会往偏重的一侧倾斜 |
| 9 | 流沙池 | 在流沙上停留会下陷、减速；需要踩着垫脚石过去 |
| 10 | 星象视错觉 | 俯视转到指定角度，断掉的阶梯才接上（复用断桥的平移机制） |
| 11 | 最终考验 | 塌陷地板、飞镖、滚石组合 |
| 12 | 法老墓室 | 黄金墓室，石棺做灵台，结算 |

**美术**：外景是金色黄昏的沙漠；内部是砂岩墙面加象形文字饰带，配火把暖光、金色装饰和深色深渊。用 Lux3D 生成斯芬克斯、阿努比斯雕像、法老石棺，可能再加一个圣甲虫；生成失败时用代码拼的简化版顶上。

**时长**：每个房间按人类玩家 3–5 分钟设计，靠试玩来校准。

## 测试

- 原有测试保持可用（中式关）：`--bot`、`--noalign`、`--lonetest`、`--solotest`、`--duotest`、联机 `--nettest`
- 新增 `--level=<id>`、`--room=N`：电脑队伍从指定房间出发，必须走到下一个房间（或灵台）
- 新增 `--levelbot`：电脑队伍从第 1 个房间走完整关，验证送达和结算
- 每批房间截俯视图和第一人称图

加纳、墨西哥、日本三关；3–4 人联机；音乐音效。
