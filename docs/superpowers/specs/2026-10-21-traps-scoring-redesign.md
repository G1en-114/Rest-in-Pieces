# 机关库、计分重做、前两关重做

日期：2026-10-21 · 分支 feature/levels

## 起因（试玩反馈）

- 玩到后面体面值普遍是 -3000 多：倾斜按秒扣分，棺材侧翻在地上时每秒掉十几分；撞墙“砰”没有冷却。
- 评分太单一，只有一个体面值。
- 路线基本只有一条；关卡整体单调，想要 I wanna 那种“坑人”的机关。
- 墨西哥关初学者 10 分钟就通过了，还要加内容。

## 1 计分

体面值只按**事件**扣，不再按秒扣：

| 事件 | 体面 |
| --- | --- |
| 颠了一下（逝者在棺材里、棺材倾斜越过 35°；回到 20° 以内才重新计） | -2 |
| 逝者掉出来 | -10 |
| 整队坠落 | -20 |
| 棺材摔在地上 | -8 |
| 棺材撞上硬物（1.5 秒冷却） | -3 |
| 被机关撞飞 | 不扣分（棺材因此掉了才扣） |

另外记这些数，结算时显示：颠了几下、掉出、坠落、被撞飞几次、花圈 x/总数、秘密 x/总数、抄了哪条近路、零失误房间数、最长“稳稳当当”的时间（期间没颠、没掉、没摔、没被撞飞）。

结算加分：逝者在棺材里 +20、全程没掉出来 +10、用时低于标准 +10、花圈全收集 +15、每个秘密 +5（发现时就加）、每个零失误房间 +3。
评级：S ≥ 150、A ≥ 115、B ≥ 85、C ≥ 55。

另有**奖章**（不加分，图个乐）：空中飞人（被撞飞 ≥ 5 次）、稳如泰山（连续稳 90 秒）、探险家（秘密全找到）、花圈收割机（花圈全收集）、抄近路、一镜到底（没掉没摔）、深渊常客（坠落 ≥ 5）、逝者想自己走（掉出 ≥ 5）。

## 2 机关库（scripts/trap.gd + scripts/traps.gd）

每个机关是一个 Trap 节点：外观和碰撞只看时间和“触发时间” t0 摆放（两边各算各的，联机只同步 t0），房主负责判断触发、打人。
被打中的人调 `Bearer.knock()`：松手、飞出去、晕一下。

| 机关 | 说明 |
| --- | --- |
| Spikes 地刺 | 踩到（或走近）触发区，地刺从地里弹出来把人顶飞；也可以按周期自己弹 |
| Dropper 天降 | 头顶挂着的东西（花圈、石块、彩罐），人走到下面就砸下来 |
| FakeFloor 假地板 | 看着是地，踩上去一会儿就塌，过几秒再长回来 |
| Spring 弹簧板 | 踩上去整组（连同抓着的棺材）弹飞，用来抄近路 |
| Piston 推墙 | 墙里周期性冲出来的石块，把人推飞 |
| Pendulum 摆锤 | 来回荡的锤子 / 香炉 / 刀 |
| Crusher 压板 | 天花板上的压板周期性砸下来 |
| Conveyor 传送带 | 站上去会被带着走 |
| Mover 移动平台 | 两点之间来回开的平台，站在上面跟着走 |
| Roller 滚石 | 周期性从坡顶滚下来的大石球 |

关卡里另有：假墙（看着是墙，能穿过去，后面藏着秘密房间和花环）、近路区（走进去记一次“抄近路”）、秘密区。
电脑队伍在 `"wait:trap:<名字>:<秒>"` 处等这个机关接下来若干秒都伤不到人。

## 3 中国关「殡仪馆的一天」

原来的停棺间、走廊、断桥、灵堂保留，在南边加三间，原来的停棺间变成“停尸间”：

1. 停棺间（新起点，教学）
2. 告别厅：三条过道。中间过道荡着三个大香炉（摆锤）；西边过道头顶挂着花圈，走到下面就砸（天降），还有一块假地板；东边过道铺着往回走的红毯（传送带）。遗像后面是假墙，藏着秘密小间。
3. 纸扎仓库：两边墙里周期性冲出纸扎压板（推墙），中间一台压纸机（压板）。角落一块弹簧板能把整队弹上二楼货架走廊，绕过推墙（近路）。
4. 停尸间（原停棺间）：一排冰柜抽屉周期性弹出来（推墙）
5. 走廊（原来的推车、湿地板，台阶上加了地刺）
6. 断桥（原来的俯视断桥）
7. 灵堂：灵台第一次被走近时会往后滑开（“还没准备好”），之后再回来

## 4 埃及关「法老的最后一程」

前四间加机关和岔路，临时墓室挪到最后，中间加两间：

1. 沙漠入口：加天降落石、沙堆迷宫里一块弹簧板近路
2. 飞镖甬道：西段加推墙；地刺
3. 塌陷地板厅：加地刺、压板
4. 封印石门：原样
5. 滚石长廊（新）：上坡，坡顶周期性滚下石球，两边有壁龛可以躲
6. 刀摆深渊（新）：两条路过深坑——窄桥上有三把摆刀（快），或者坐升降 / 移动平台（慢但稳）
7. 法老墓室：灵台旁的地板是假的，石棺盖子会砸下来

## 5 墨西哥关加内容

- 墓园：有坟里会伸出骷髅手（地刺）；有一个坟是假地板
- 集市：摊位遮阳棚上有弹簧板，能弹到棚顶的高处路线，上面有花环
- 运河：除了花船，还能踩着漂着的万寿菊木筏（移动平台）过去
- 新房间「烟花城堡」（集市和运河之间）：转着的烟花轮（两层高度的转臂）、喷火的炮台（周期弹射物）、压板
