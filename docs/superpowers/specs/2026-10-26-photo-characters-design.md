# 照片角色与用户自带密钥

用户已要求实现照片生成角色，并明确使用玩家自己的平台 API key。

主菜单新增角色工作台，支持为玩家一、玩家二和逝者选择 PNG/JPEG 全身照片，输入仅驻留内存的 AHOLO API Key，选择国内或国际官方 API，生成 GLB 并自动绑骨后应用。无需 Python、SDK 或额外服务器。生成中可返回菜单，客户端保留任务阶段及任务号，可继续查询而不是重复扣费创建。取消只停止本地等待，不能宣称取消远端计费任务。

通过官方 Asset/OUS 上传图片，再调用 Lux3D 图生 3D、任务轮询及人形自动绑骨。使用原始 Authorization 值；国际 API 使用 /global 前缀。所有远端文件有大小和时间限制。密钥不存盘、不记录日志、不传给联机队友。

模型作为外观附着在现有物理身体上。新模型必须具有可适配的人形骨架；失败保留旧模型。抬棺人保留原有刚体、双手和第一人称遮挡。逝者保留原有六个刚体和关节，通过骨架适配显示生成外观。保存导入模型到 user://characters，重启可恢复外观；照片和密钥不保存。联机仅同步模型数据；不修改物理快照中的刚体顺序或数量。

验收：离线假 API 验证完整上传→生成→绑骨→下载、错误、取消、超时和任务恢复；Godot 检查新模型、损坏模型回退、逝者物理结构不变；双人和联机回归；作品描述按完成内容撰写，真实 API 生成未验收时须说明。
