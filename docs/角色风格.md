# 角色风格（已定稿：2026-10-20）

抬棺人和逝者统一用 **bearer_v2** 的风格：参考 How to Fish 的滑稽人物。

- 光头，没有脖子，头部是竖直拉长的大拇指形或花生形，肉色
- 两只外凸的大圆眼珠，长在头部侧上方；没有嘴，可以有一个小鼻子
- 身材瘦长，细长的胳膊和腿，简单的几何体肢体
- 低多边形，纯色平涂。生成出来偏光滑塑料感，在 Godot 里用平涂卡通着色器统一成哑光效果
- 生成参数：Lux3D text-to-3d，`style=cartoon`，`version=G1`，`faceCount=20000`，耗时约 4.5 分钟

标准模型：`generated/bearer_v2/1_textured.glb`（T 字姿势，高约 1.77 m）
备用预设：`generated/bearer_v1/1_textured.glb`（矮胖 Q 版保镖，风格不同，留作彩蛋）

游戏默认加载的是 `game/assets/bearer.glb`，来自 `generated/bearer_v2_rig/` 的 Lux3D 自动绑骨结果。上面的标准模型是绑骨前的生成结果。现在也可在主菜单「自定义角色」中，用自己的密钥和照片生成模型，或导入已有 GLB，替换两名抬棺人及逝者的外观。逝者的胶囊刚体和关节由 `game/scripts/corpse.gd` 保留，生成模型的骨架随这些物理部件运动。完整接入边界见 [Lux3D 接入说明](Lux3D接入说明.md)。

## 提示词模板

抬棺人（已验证效果）：

> 低多边形卡通游戏角色，平涂纯色，没有贴图细节。光头，没有脖子，头部是竖直拉长的花生形或大拇指形，肉色皮肤，两只外凸的大圆眼珠长在头部侧上方，没有嘴巴，表情呆滞滑稽。身材瘦长，长手臂长腿，简单的几何体肢体。穿黑色西装外套、白衬衫、黑领带、黑裤子、黑皮鞋，像抬棺舞里的抬棺人。T 字姿势站立，双臂水平伸直，正面，全身，单个角色

换角色时只改“穿……”那一句（衣服、配饰），其余部分保持不变，以保证风格统一。
